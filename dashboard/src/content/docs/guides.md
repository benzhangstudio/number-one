# Guides

**Category:** 🎨 Cosmetics · **Recommended:** yes

Two ready-to-edit guides you can post in your server: a **Server guide** for members and a **Staff guide** for your team. Each one is posted as a tidy set of messages with a linked contents list at the bottom, so it reads like a small handbook. Start from a ready-made template or a blank one.

## Quick setup

1. Switch on **Guides** on the dashboard.
2. Pick a guide, pick its channel and switch it on.
3. Edit the ready-made text.
4. Click **Save changes**. The guide is posted.

## The two guides

| Guide | For | Starts with |
| --- | --- | --- |
| 👥 Server guide | Members | Welcome, rules, roles, channels, getting help |
| 🛡️ Staff guide | Your team. Post it in a staff-only channel. | How we moderate, moderation commands, handling tickets, when to escalate |

Each guide has its own on/off switch and channel. Switching one off takes it down but keeps its text.

## How a guide is posted

Guides are posted as **plain messages**, so members just scroll. There's nothing to press to read them.

1. **Sections:** each section is its own embed with a title, an emoji, text with Discord formatting and mentions (up to 4,000 characters) and an optional image. Sections are numbered like "2 of 5".
2. **Contents:** the last message, at the bottom, has the guide's title, an intro (up to 1,500 characters) and a list of sections. Each item is a link that jumps straight to that section. Discord opens a channel at its newest message, so readers see the contents first without scrolling up.
3. **Navigation:** under each section, **Contents** and **Next: …** link buttons. These can be switched off.

Up to 20 sections per guide.

## Editing

- Both guides start with ready-made text. Edit anything you like.
- **Start from a template** replaces a guide's title, intro and sections (the channel and switches stay the same):

| Template | What's in it |
| --- | --- |
| 📄 Blank | Three empty sections, already linked together. Write your own. |
| 👥 Server guide | Welcome, rules, roles, channels and getting help. |
| 🛡️ Staff guide | How to moderate, moderation commands, tickets and when to escalate. |
| ❓ FAQ | Answers to the questions members ask most. |
| 📜 Rules | Five rules, one per section, easy to link to. |
| 🎭 Roles | Staff, level, self-picked and special roles. |
| 🎉 Events | What you host, how to join, event rules and hosting your own. |

- Guides posted before the contents moved to the bottom still have it at the top. Save the guide once and it's posted again with the contents at the bottom.
- **Saving** updates the messages in place.
- Adding, removing or moving sections, or picking another channel, removes the old messages and posts the guide again, so it always reads top to bottom.

## The dashboard

- Previews the guide as it reads in the channel.
- Links to each posted guide.
- Warns you if the Staff guide's channel can be seen by everyone, or if part of a guide was deleted in Discord.

## Switching it off

Switching the whole module off takes both guides down. Their text stays saved.

## Permissions

**View Channel**, **Send Messages**, **Embed Links** and **Read Message History** in each guide's channel.
