# Number One updates

**Category:** 🧩 Other · **Recommended:** yes

Get news about Number One itself (new features, fixes, planned downtime) posted in a channel you choose. Updates come from Number One's developer, not from your staff.

## Quick setup

1. Switch on **Number One updates** on the dashboard.
2. Pick the channel to post in.
3. Optional: pick a role to mention, so the right people see each update.
4. Click **Save changes**, then **Send a test** to check I can post there.

## Good to know

- Without a channel, your server doesn't get updates at all.
- Each update is posted once. Nothing is sent by DM.
- The developer can choose to post an update without mentioning anyone.
- To stop getting updates, switch the module off or clear the channel.

## Permissions

In the updates channel I need **View Channel**, **Send Messages** and **Embed Links**. To mention a role, it must be mentionable, or I need **Mention @everyone, @here and All Roles**.
