# Channel designs

**Category:** 🎨 Cosmetics · **Recommended:** yes

Adds a cute design around every channel's name in one click, like `general` → `💬・general` or `꒰💬꒱general`. Only the design is added. Everything else about your channels stays the same, and you can remove it any time.

## Quick setup

1. Switch on **Channel designs** on the dashboard.
2. Pick a design and check the before-and-after list.
3. Click **Apply**.

## Which channels

| Setting | Default | Notes |
| --- | --- | --- |
| Text channels | Always | |
| Announcement channels | Off | |
| Voice and stage channels | Off | |
| Skipped channels | None | Up to 50 channels or whole categories left exactly as they are. |
| Design new channels | Off | Channels created later get the design too. |

Categories and forums are never renamed. Names that would go over Discord's 100-character limit are skipped.

## Safe by design

- **Only the name changes.** Permissions, topic and position stay the same.
- Each channel's own name is saved, so switching designs never stacks them, and **Remove design** puts every name back exactly.
- If someone renames a designed channel by hand, that new name becomes its own name.

## Rate limits

Discord lets each channel be renamed only **twice every 10 minutes**. The dashboard shows progress while renaming, and switching designs quickly can take a few minutes to finish. Channels that couldn't be changed are listed with the reason.

## Switching it off

Switching the module off leaves names as they are. Use **Remove design** first if you want the original names back. Deleting the server's data also puts the original names back.

## Permissions

**Manage Channels**, for both Number One and the admin applying the design.
