# Suggestions

**Category:** 🎉 Engagement & Fun · **Recommended:** yes

Let members share ideas for the server and vote on them. Staff mark each idea as approved, implemented or denied, and the member hears back.

## Quick setup

1. Switch on **Suggestions** on the dashboard.
2. Pick the channel where suggestions are posted.
3. Click **Save settings**. Members can now use `/suggest`.

## How it works

1. A member types `/suggest`. A short form asks for the idea and optional details.
2. Number One posts it in the suggestions channel as **#1**, **#2** and so on, with 👍 and 👎 buttons. The vote counts are on the buttons and update live.
3. A discussion thread opens under each suggestion, if switched on.
4. Staff set a status, with an optional response. The post updates, and the member gets a DM.

Pressing your vote again takes it back. Pressing the other button changes it.

## Statuses

| Status | What it means |
| --- | --- |
| 🗳️ Open for votes | New. Everyone can vote. |
| 🤔 Being considered | Staff are looking at it. Voting stays open. |
| ✅ Approved | It's going to happen. Voting stays open. |
| 🎉 Implemented | Done! Voting closes and the thread is closed. |
| ❌ Denied | Not happening. Voting closes and the thread is closed. |

## Settings

| Setting | Default | Notes |
| --- | --- | --- |
| Suggestions channel | None | Where suggestions are posted. |
| Wait between suggestions | 5 minutes | Per member. Staff don't wait. |
| Discussion thread | On | A thread under each suggestion. |
| Anonymous | Off | Hides who sent it on the post. Staff still see it on the dashboard. |
| DM the member | On | When the status changes. |
| Reviewer roles | None | People with **Manage Server** or **Manage Messages** can always review. |

## Reviewing on the dashboard

The dashboard lists the newest 100 suggestions with their votes, and you can filter by status. Press **Review** to set a status and response, or **Delete** to remove a suggestion with its post, thread and votes.

## Commands

| Command | Who | What it does |
| --- | --- | --- |
| `/suggest` | Everyone | Opens a form to send a suggestion. |
| `/suggestion status number status [reason]` | Reviewers | Sets a suggestion's status, with an optional response. |

## Permissions

- **View Channel**, **Send Messages** and **Embed Links** in the suggestions channel.
- **Create Public Threads** there for discussion threads.
