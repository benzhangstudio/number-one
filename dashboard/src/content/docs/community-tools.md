# Community tools

**Category:** 👥 Community Settings · **Recommended:** yes

Switch on Discord's Community features in one click, make announcement channels, and edit Discord's Welcome Screen and onboarding, all from the dashboard. Number One doesn't store any of this: every change goes straight to Discord.

## Switch on Community

Discord's Community features unlock announcement channels, the Welcome Screen and Discord's own onboarding. The dashboard shows exactly what will change first:

- The verification level goes up to **Low** (members need a verified email to chat), if it was lower.
- Discord's **media filter** is turned on for all members.
- A **rules channel** and a staff-only channel for **updates from Discord** are set. Pick your own, or Number One makes `#rules` and `#moderator-only` (hidden from @everyone).

Only the **server owner** or someone with **Administrator** can switch Community on or off.

## Announcement channels

Posts in announcement channels can be **published**, so servers that follow the channel get them too.

- **Make announcement / Make text:** changes an existing text channel into an announcement channel and back. Messages, permissions and the name stay the same.
- **Make announcement channel:** creates a new one, read-only for @everyone so only staff can post.
- Discord keeps the rules and updates channels as text channels.

The [Announcements](/docs/announcements) module can publish posts automatically when it sends to an announcement channel.

## Welcome Screen

What people see when they first open your server: a short description (up to 140 characters) and up to 5 channels to start in, each with a short description and an optional emoji.

## Discord's onboarding

Discord's own questions and default channels for new members.

- **Default channels:** everyone sees these. Discord needs at least **7**, and at least **5** where @everyone can send messages, before onboarding can be on.
- **Questions:** each answer gives roles, shows channels, or both. Questions can allow one or several answers, be required, and be asked while joining or only later in Channels & Roles.

> ⚠️ If Number One's [Member onboarding](/docs/onboarding) is also on, new members go through both. Use one or the other.

## What Number One can't do

Discord doesn't let bots set up the **Server Guide** (its welcome message, new member to-dos and resource channels). Add those yourself in Discord: **Server Settings → Onboarding → Server Guide**. For a guide Number One posts and keeps up to date, use [Guides](/docs/guides).

## Permissions

- **Manage Server** for Community, the Welcome Screen and onboarding.
- **Manage Channels** to make or change announcement channels.
- **Manage Roles** for onboarding answers that give roles.
- Number One is invited with Administrator, which covers all of these.
