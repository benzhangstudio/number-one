# Embed messages

**Category:** 🛠️ Utilities & Automation · **Recommended:** yes

Build good-looking messages with embeds on the dashboard and Number One posts them. Great for info channels, server menus and anything you want to look polished.

## Quick setup

1. Switch on **Embed messages** on the dashboard.
2. Click **New message**, pick a channel and build your message.
3. Check the live preview, then click **Post**.

## What a message can have

- **Text** above the embeds, up to 2,000 characters.
- **Up to 10 embeds**, each with:

| Part | Notes |
| --- | --- |
| Colour | The embed's side colour. |
| Author | A name, with an optional icon and link. |
| Title and link | The title can link to a web page. |
| Description | The main text, with Discord formatting. |
| Fields | Up to 25 name/value pairs, side by side or full width. |
| Images | A big image and a small thumbnail. |
| Footer | Small text at the bottom, with an optional icon. |
| Time | Shows when the message was posted (or last edited). |

A **live preview** shows exactly how it will look in Discord. The builder warns you before saving if something would go over Discord's limits (for example, 6,000 characters across all of one message's embeds).

## Managing messages

- **Edit** a saved message and the message in Discord changes too.
- **Move** it to another channel.
- **Delete** it from the dashboard and Discord.
- An internal **name** (only shown on the dashboard) helps tell messages apart.
- Up to 100 saved messages per server.
- If a message is deleted in Discord, it's removed from the list. Editing one that was deleted posts it again.

## Good to know

- Mentions in the text show up but **never ping** anyone. For pings, use [Announcements](/docs/announcements).
- Admins can only post in channels where they could post themselves.

## Permissions

**View Channel**, **Send Messages** and **Embed Links** in the chosen channel.
