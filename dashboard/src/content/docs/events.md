# Events

**Category:** 🎉 Engagement & Fun · **Recommended:** yes

Plan game nights, meetups and community events with RSVP buttons, automatic reminders and a matching entry in Discord's own Events tab. Everything is set up on the dashboard.

## Quick setup

1. Switch on **Events** on the dashboard.
2. Click **New event**, fill in the name, time and place, and pick a channel.
3. Tick **Add to Discord Events** if you want it in the server's Events tab too.
4. Click **Post**.

## The event post

| Part | Notes |
| --- | --- |
| Name and description | Shown on the post (and copied to Discord's Events tab). |
| Start and end time | Everyone sees the times in **their own time zone**, with a countdown. The end time is optional. Events can start up to a year ahead. |
| Where | A place or link (somewhere in the world or online), or a voice or stage channel in your server. |
| Cover image and colour | Optional picture and the card's side colour. |
| Ping | None, @everyone, @here or chosen roles, sent once when the event is posted. |

## RSVPs

The post has three buttons:

| Button | Meaning |
| --- | --- |
| ✅ Going | Counts towards the limit, if there is one. |
| ❔ Maybe | Always available, even when the event is full. |
| ❌ Can't go | Lets the host know. |

- A live list of who answered is shown on the post.
- Pressing your current answer again takes it back.
- **Attendee limit:** optional. When it's full, people can still pick Maybe.

## Reminders

Number One DMs everyone who answered Going or Maybe before the event starts. Pick how long before (1 hour by default), or no reminder.

## When the event ends or is cancelled

- **After it ends**, the post is marked as ended and its buttons are removed.
- **Cancelling** marks the post as cancelled and DMs everyone who was going or maybe going.

## Discord's Events tab

Tick **Add to Discord Events** when creating an event, or press the button later, and Number One makes a matching Discord scheduled event with the same name, time, place, description and cover image, plus a link back to the post. Nobody has to set it up by hand.

- Edits are copied to the Discord event.
- Cancelling or deleting the event removes the Discord event.
- It shows as **live** in Discord when the event starts.
- Events without an end time show as lasting 1 hour in the Events tab.

## Managing events

The dashboard lists upcoming events (soonest first) and the last 20 past or cancelled ones, with answer counts and who's coming. You can **edit**, **copy**, **cancel** or **delete** any event. Up to 50 upcoming events per server.

## Permissions

- **View Channel**, **Send Messages** and **Embed Links** in the event channel.
- **Manage Events** for Discord's Events tab.
- **Mention @everyone, @here and All Roles** for those pings.
- Admins need **Manage Events** (or **Create Events**) themselves to add events to the Events tab.
