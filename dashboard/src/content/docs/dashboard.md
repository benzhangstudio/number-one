# Using the dashboard

The dashboard is where almost everything in Number One is set up. It works on desktop and phone, in light or dark mode.

## Logging in

1. Click **Log in** in the top menu.
2. Approve "Log in with Discord".
3. You're taken to your home page.

Login sessions last up to 7 days. Click your name in the top right and pick **Log out** to end it early.

## Your servers

**My servers** lists every server where you have the **Manage Server** permission. Servers without Number One show an **Add bot** button.

This permission is re-checked with Discord on **every** request. If someone loses Manage Server in Discord, they lose dashboard access straight away.

## A server's page

Each server's page has a menu down the side: **Overview**, **Choose features**, then each category and its modules. Each module page has:

- An **on/off switch** at the top.
- Its **settings**, with a **Save changes** button that stays disabled until something has changed.
- A **Needs attention** box when something's wrong, like a deleted channel or a missing permission, explained in plain words.
- Live previews and stats where they help, like how a message will look in Discord or how many members finished onboarding.

**Choose features** works like `/setup`: pick categories and their recommended modules switch on.

## Undo

After every settings save (a module's **Save changes**, an on/off switch, or **Choose features**), an **Undo** button appears at the top right for 8 seconds. Clicking it puts the previous settings back.

- Only the latest save can be undone.
- Things that have already gone out in Discord (an announcement, an embed message, an event, a role menu) don't offer undo. Edit or delete them instead.

## Announcements page

The **Announcements** page in the top menu is Number One's own news: new modules, changes and fixes. A dot appears in the menu when there's something you haven't seen.

## Light and dark mode

Use the theme switch in the top bar. Your choice is remembered on that device.

## Colors

Not a fan of pink? Click the 🎨 button in the top bar and pick a color: pink, red, orange, gold, green, teal, blue, purple or mono. It works in both light and dark mode and is remembered on that device. It only changes how the dashboard looks to you, not the bot's messages in Discord.
